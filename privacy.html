NHL SOG Rankings — Privacy Policy

Effective date: October 14, 2026.

NHL SOG Rankings is an owner-operated personal hockey research project. This notice describes its data practices. Automated scheduling remains uninstalled while authorization and operational checks are completed.

Information accessed and purpose

The application uses public NHL schedules, player information, and game statistics to produce experimental rankings and track forecast outcomes. It reads and updates the operator's designated Google Sheets workbook and stores project caches, source evidence, forecast records, and recovery backups in designated private Google Drive resources.

Google authorization requests Sheets and Drive permissions. These permissions are broad at the OAuth level; the project code restricts routine operations to its registered project resources. Google data is used to operate, verify, recover, and maintain this personal research tool.

Processing, storage, and access

Private Google Sheets and Drive resources and GitHub Actions are used for project operations. A small Google Apps Script timing coordinator is planned. Operational logs may contain timestamps, execution status, request counts, and sanitized diagnostics. Credentials are held in private credential stores, not public website source. Access is limited to the operator and services or collaborators the operator authorizes.

This public website does not display private workbook contents, forecast ledgers, or credentials. It has no application sign-in, submission form, advertising, custom analytics, or client-side tracking scripts. GitHub, the hosting provider, may process ordinary connection and security information under its Privacy Statement.

Sharing and restricted uses

The project does not sell Google user data or use it for advertising. It does not use Google user data to train generalized AI models. Scheduled ranking calculations use deterministic project code. The project does not access sportsbook credentials or place bets.

NHL SOG Rankings' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

Project evidence, forecast history, and backups are retained for research reproducibility and recovery until the operator removes or archives them. Revoking Google access stops future authorized access but does not automatically delete stored records. The operator can delete project files, dedicated private credentials, and backups through the respective Google and GitHub accounts, subject to provider retention rules.

Your controls and contact

The operator can revoke access through Google Account connections, disable scheduled automation when installed, and delete the dedicated stored credential. For privacy questions or deletion requests, use the support email shown on the Google authorization screen or contact the operator through the public information repository. Never post tokens, private file links, account details, or sensitive information publicly; request a private contact route instead.

Changes

This notice will be updated before material changes to data access, sharing, or hosting practices.
